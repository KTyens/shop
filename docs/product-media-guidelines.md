# Product Media Guidelines

Use this media standard when adding TV Box or projector products to shop.crtlu.me.

## Homepage Cards

- Use a real product image whenever available.
- Prefer a clean product set image with the main device plus remote or key accessories.
- Avoid using abstract CSS placeholders after real product photos are available.
- Keep images on a clean background and compress to a maximum width of about 1200px.

## Product Detail Gallery

Recommended content types after the two product shots:

1. Usage or living-room / TV scene images
2. Spec, parameter, chipset, or performance graphics
3. Display, 4K, 8K, HDR, or visual-experience images
4. Interface / port diagrams and size diagrams
5. Remote, mouse assistance, Wi-Fi, Bluetooth, packing-list, and accessory images

## Gallery Mix Rule (mandatory)

Updated 2026-11-11. A gallery must not be only the product from different angles. Compare with `x96-max-plus-ultra` (18 images) and `h96-max-v58`.

- Order: **exactly 2 clean product shots first** (`main.jpg` first, then `detail-1.jpg`), then **all remaining images are content images**.
- Do not add extra product-angle shots beyond those 2. Extra angles belong in the supplier archive, not the live gallery.
- Content images = usage/scene images, spec/parameter/feature graphics (Wi-Fi, Bluetooth, 4K/HDR, system), interface/port diagrams, size diagrams, package contents, chip/performance graphics, and apps/marketing graphics.
- Include as many qualifying content images as the supplier folder has, up to a cap of about 18 images in total, unless a few more are clearly useful.
- Files stay `main.jpg` + `detail-N.jpg`; square, ~1200px, each file ideally <= 300KB.
- Every content image must be consistent with the catalog `specs` (chip, RAM/ROM, Wi-Fi/Bluetooth version, 4K/8K, dimensions). A graphic that lists a superset of the sold RAM/ROM options is fine; anything that contradicts a sold spec is not.
- Trademark and brand-logo images, including streaming-app logo collages and "apps" marketing graphics, **are allowed**. This independent store is not as strict as Amazon about third-party trademarks. Genuine certification logos (CE, RoHS, FCC) are also fine.
- Reject (do not publish) images that contain:
  - other platforms'/sellers' watermarks, URLs, QR codes, website names or contact info;
  - price text;
  - IPTV / free movies / free channels claims, or "unblock" wording;
  - fake reviews ("Verified Buyer"), real-person names presented as buyer reviews, or unverifiable percentage comparison claims ("Enhance 70%", "Cheap Factory Chip");
  - chip/RAM/spec text that contradicts the catalog, or unverifiable inflated claims (e.g. Wi-Fi 6 / 8K on a product that does not have it);
  - Chinese-text or non-English packaging images (unless nothing better exists);
  - near-duplicates.
- If a supplier folder has no usable content images, publish the 2 clean product shots and ask the owner for more scene/spec/port/accessory images rather than padding with angle duplicates.
- If a folder has fewer than 2 clean product shots, use what exists, fill the rest with content images, and report the gap.

## Images To Avoid

- Avoid images that imply bundled paid subscriptions, preloaded IPTV, or unofficial access.
- Avoid low-resolution screenshots when a cleaner product or feature image exists.

## Naming

Use stable lowercase names in each product asset folder:

- `main.jpg`
- `android.jpg`
- `chipset.jpg`
- `visual.jpg`
- `mouse.jpg`
- `wifi.jpg`
- `cast.jpg`
- `bluetooth.jpg`
- `ports.jpg`
- `packing.jpg`

For new batch galleries on this site, prefer the numbered pattern `main.jpg` + `detail-N.jpg`.
