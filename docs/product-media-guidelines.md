# Product Media Guidelines

Use this media standard when adding TV Box or projector products to shop.crtlu.me.

## Homepage Cards

- Use a real product image whenever available.
- Prefer a clean product set image with the main device plus remote or key accessories.
- Avoid using abstract CSS placeholders after real product photos are available.
- Keep images on a clean background and compress to a maximum width of about 1200px.

## Product Detail Gallery

Recommended order:

1. Main product set image, preferably device plus remote.
2. System or Android version feature image.
3. Chipset or performance image.
4. Display, 4K, 8K, HDR, or visual experience image.
5. Remote, mouse assistance, Wi-Fi, Bluetooth, casting, ports, and packing list images.

## Images To Avoid

- Avoid hero or gallery images dominated by large third-party streaming brand logos.
- Avoid images that imply bundled paid subscriptions, preloaded IPTV, or unofficial access.
- Avoid low-resolution screenshots when a cleaner product or feature image exists.

## Naming

Use stable lowercase names in each product asset folder:

- `main.jpg`
- `android.jpg`
- `chipset.jpg`
- `visual.jpg`
- `mouse.jpg`
- `wifi.jpg`
- `cast.jpg`
- `bluetooth.jpg`
- `ports.jpg`
- `packing.jpg`
