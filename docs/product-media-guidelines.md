# Product Media Guidelines

Use this media standard when adding TV Box or projector products to shop.crtlu.me.

## Homepage Cards

- Use a real product image whenever available.
- Prefer a clean product set image with the main device plus remote or key accessories.
- Avoid using abstract CSS placeholders after real product photos are available.
- Keep images on a clean background and compress to a maximum width of about 1200px.

## Product Detail Gallery

Recommended order:

1. Main product set image, preferably device plus remote.
2. System or Android version feature image.
3. Chipset or performance image.
4. Display, 4K, 8K, HDR, or visual experience image.
5. Remote, mouse assistance, Wi-Fi, Bluetooth, casting, ports, and packing list images.

## Gallery Mix Rule (mandatory)

A gallery must not be only the product from different angles. Compare with `x96-max-plus-ultra` (18 images) and `h96-max-v58`.

- Order: first 4-6 clean product shots (`main.jpg` first, then `detail-1..`), then at least ~6 content images, up to a cap of 18 images in total.
- Content images = usage/scene images, spec/parameter/feature graphics (Wi-Fi, Bluetooth, 4K/HDR, system), interface/port diagrams, size diagrams, package contents, chip/performance graphics.
- Files stay `main.jpg` + `detail-N.jpg`; square, ~1200px, each file ideally <= 300KB.
- Every content image must be consistent with the catalog `specs` (chip, RAM/ROM, Wi-Fi/Bluetooth version, 4K/8K, dimensions). A graphic that lists a superset of the sold RAM/ROM options is fine; anything that contradicts a sold spec is not.
- Reject (do not publish) images that contain:
  - other platforms'/sellers' watermarks, URLs, QR codes, website names or contact info;
  - other brands' logos or any brand that is not the product's own;
  - price text;
  - IPTV / free movies / free channels claims, streaming-app icon collages or boxes with a streaming-logo strip, "unblock" wording;
  - fake reviews ("Verified Buyer"), real-person names, or percentage comparison claims ("Enhance 70%", "Cheap Factory Chip");
  - chip/RAM/spec text that contradicts the catalog, or unverifiable inflated claims (e.g. Wi-Fi 6 / 8K on a product that does not have it);
  - Chinese-text or non-English packaging images (unless nothing better exists);
  - near-duplicates.
  Genuine certification logos (CE, RoHS, FCC) are fine.
- If a supplier folder has no usable content images, publish the clean product shots and ask the owner for the full supplier folder rather than padding with angle duplicates.

## Images To Avoid

- Avoid hero or gallery images dominated by large third-party streaming brand logos.
- Avoid images that imply bundled paid subscriptions, preloaded IPTV, or unofficial access.
- Avoid low-resolution screenshots when a cleaner product or feature image exists.

## Naming

Use stable lowercase names in each product asset folder:

- `main.jpg`
- `android.jpg`
- `chipset.jpg`
- `visual.jpg`
- `mouse.jpg`
- `wifi.jpg`
- `cast.jpg`
- `bluetooth.jpg`
- `ports.jpg`
- `packing.jpg`
